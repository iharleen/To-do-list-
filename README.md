# To-Do List Application

## Project Overview
This is a simple Python-based To-Do List Application that helps users manage their daily tasks. Users can add, view, complete, and delete tasks to keep track of their work.

The project is designed to practice basic Python programming concepts and task management.

## Features
- Add new tasks.
- View all tasks.
- Mark tasks as completed.
- Delete tasks.
- Manage daily activities through a simple menu-driven interface.

## Technologies Used
- Python

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Run the Python file:

```bash
python todo_list.py
```

4. Follow the menu options to manage your tasks.

- Loops

- User input and output
